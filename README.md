# decentralized-proof-of-contact-network

> Decentralized proof-of-contact network – generates signed proofs verifying that nodes communicated during specific orbital windows

## Overview

This repository is part of the [quantumworld-dpdns-io](https://github.com/quantumworld-dpdns-io) Wild SaaS & Tech Development initiative.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/quantumworld-dpdns-io/decentralized-proof-of-contact-network.git
cd decentralized-proof-of-contact-network
```
